# Commission Referral App

A mobile-friendly starter prototype for a legal, sale-based referral commission platform.

## Core rule
Commission is generated from verified product/service sales, not from recruiting members or entry/deposit fees.

## Prototype
- User dashboard
- Referral code/link
- Product catalogue
- Sale-based commission calculation
- Commission history
- Wallet summary
- Admin demo section

This is a frontend prototype. Authentication, database, payment gateway, KYC and production security should be added before real-money deployment.
